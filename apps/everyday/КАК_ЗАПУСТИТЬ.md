# SecureEquipment — запуск

## Первый локальный запуск

```powershell
cd "C:\путь\к\проекту"
npm ci
npm run dev
```

Откройте `http://localhost:3000`. Rust-узел работает на
`http://127.0.0.1:8080`; Vite проксирует `/api` к нему.

На новой пустой базе зарегистрируйте первого владельца. После этого свободная
регистрация закрыта: следующий сотрудник входит по QR/ссылке приглашения.

Демо-режим включается только явно и не предназначен для production:

```powershell
$env:MESHKEEPER_DEMO_DATA='1'
$env:MESHKEEPER_DEMO_LOGIN='1'
npm run dev
```

## Production-сборка

```powershell
npm run check
npm run lint
npm test
npm run build
npm run smoke
npm start
```

По умолчанию сервер доступен только на этом компьютере. Для доступа из LAN нужен
HTTPS reverse proxy и secure cookie:

```powershell
$env:MESHKEEPER_BIND='0.0.0.0:8080'
$env:MESHKEEPER_COOKIE_SECURE='1'
npm start
```

Не публикуйте порт напрямую в интернет. Ограничьте firewall и передавайте трафик
через HTTPS reverse proxy.

## База и резервные копии

База по умолчанию: `data/meshkeeper-rs.db`. Изменить путь можно переменной
`MESHKEEPER_DB`. Существующая база не удаляется командами сборки.

Шифроархив использует Argon2id + ChaCha20-Poly1305; старые архивы v1 остаются
читаемыми. Используйте пароль от 12 до 128 символов.

## Сервер и локальные узлы

Тот же бинарник работает сервером или локальным узлом — роль зависит от
переменных окружения.

Сервер (общая база, публикуется через nginx с TLS):

```powershell
$env:MESHKEEPER_SYNC_TOKEN='секрет от 32 символов'
npm start
```

Локальный узел в офисе (своя база, работает офлайн, догоняет сервер):

```powershell
$env:MESHKEEPER_SYNC_TOKEN='тот же секрет'
$env:MESHKEEPER_UPSTREAM='https://meshkeeper.example.com'
npm start
```

Без токена обмен выключен и `/sync/*` отвечает 401. Состояние связи — в
«Админка → Офлайн-узлы». Проверка связки: `npm run sync:test`.
Развёртывание сервера описано в `deploy/README.md`.

PWA даёт offline-оболочку, но не очередь offline-изменений в браузере: для
работы без интернета нужен локальный узел.
